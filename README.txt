RODA DE CONVERSA — PROJETO OFICIAL V11
======================================
Arquivos para a raiz do repositório GitHub:

index.html
style.css
script.js
RODA.jpg

Publicação:
1. Envie os quatro arquivos para a raiz do repositório.
2. Configure Settings > Pages para publicar a branch principal / root.
3. Abra o endereço do GitHub Pages após a publicação.

Funcionalidades mantidas da versão 11:
- Centro vinho-bordô metálico com seta branca e rotação rápida.
- Ordem interna de participação 1, 4, 5, 3, 6, 2, sem numeração visível.
- Controles de início, giro, registro de fala, reinício, metas e ATA.
- Três critérios de avaliação por participante e salvamento local.
- Metas da Formadora com campos editáveis.
- Exportação da ATA em DOCX, títulos azul-marinho e letras brancas.
- Sem a seção de contagem geral dos critérios na ATA.
- Cabeçalho alinhado ao canto superior esquerdo da imagem.

Observações:
- Dados salvos no navegador via localStorage; não são compartilhados entre dispositivos.
- O nome RODA.jpg diferencia maiúsculas/minúsculas em GitHub Pages.
- Para usar outra imagem posteriormente, mantenha a proporção 1672:941.
